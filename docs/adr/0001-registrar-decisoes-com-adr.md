# ADR-0001 — Registrar decisões com ADR

- **Status:** Aceito
- **Data:** 2026-11-14

## Contexto
Em projetos longos, ninguém lembra *por que* algo foi feito de certo jeito. Sem registro, as decisões são refeitas, ou pior, desfeitas sem entender as consequências.

## Decisão
Toda decisão de arquitetura ou de tecnologia que seja difícil de reverter é registrada como ADR em `docs/adr/`, via PR.

## Consequências
Existe histórico das decisões, e o novo integrante (ou você daqui a 1 ano) entende o raciocínio. O custo é escrever alguns parágrafos por decisão.
